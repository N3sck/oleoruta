# OleoRuta · Prototipo funcional MVP

Consolidación y pago digital inmediato del aceite vegetal usado del comercio informal de la CDMX.
Proyecto integrador (Sprint 2) de *Tendencias en la Transformación y Disrupción Digital*, Universidad La Salle México.

**Abrir el prototipo:** https://n3sck.github.io/oleoruta/

- Se usa directo en el navegador del celular; no hay que descargar ni instalar nada.
- Es un sitio 100 % estático servido por GitHub Pages con HTTPS.
- No usa cookies, rastreadores, analítica ni servicios de terceros.
- Tiene una política de seguridad de contenido (CSP) estricta: solo ejecuta código de este mismo sitio.
- Los datos son de muestra y se guardan únicamente en el dispositivo de quien lo abre (localStorage); nada se envía a ningún servidor.
- Los pagos, las CLABE y la API SPEI son simulados.

Para regresar al estado inicial: Más → Configuración → Restablecer datos de demostración.
